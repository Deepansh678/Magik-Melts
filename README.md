
# Magik MElts - Ignite the Enchantment

Welcome to Magik Elts, where every candle tells a story and sparks a little magic in your life. Our artisanal candles are crafted with care, blending premium waxes, enchanting fragrances, and mystical designs to create an unforgettable sensory experience.

## Features

 Responsive Design:  Adapts to various screen sizes, ensuring a seamless experience on desktop and mobile devices.

Load Products Button: A visually appealing, centered button with a gradient background and animated loading dots to engage users while loading products.

Product Grid: A dynamic and elegant grid showcasing candle collections with vibrant images, titles, prices, and an easy-to-use "Add to Cart" button.

Loading Animation: Beautifully designed animated dots within a glowing circular gradient, visually enhancing the product loading process.

## Tech Stack

- Frontend: HTML, CSS and JavaScritpt
- Styling: Advanced CSS for a polished, modern look
- State Management: Context API
- Deployment: Vercel
